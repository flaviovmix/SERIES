## ⚠️ O modelo 3D é provisório

Você pediu pra usar o ábaco de placeholder. Cada animação tem **um card 🧊 3d na tela 2**, e ele abre o
**ábaco**, com um selo laranja escrito "modelo provisório: ábaco" pra ninguém confundir.

Pra trocar quando o modelo certo existir, é um comando por episódio:

```
node "..\..\_arquivos\scripts\embute-modelo-3d.js" "animacao.html" "__MODELO3D__" "..\..\_arquivos\modelos-3d\<maquina>.html"
```

Só que o token `__MODELO3D__` já foi consumido no `animacao.html`. O caminho certo é recopiar o fonte antes:
`cp _animacao-fonte.html animacao.html` e aí rodar o comando acima. Os modelos que esta etapa pede
(válvula em corte, tubo Williams, painel do ENIAC) estão no backlog em `_arquivos\modelos-3d\_a-fazer.md`,
itens 33 a 36.
