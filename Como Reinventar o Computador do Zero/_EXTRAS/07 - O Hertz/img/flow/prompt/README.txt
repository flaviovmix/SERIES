Um prompt por cena, exatamente o que gerou o flow-<nome>-01.png.

Pra gerar de novo (com ou sem alteracao), com a janela do Flow aberta no projeto da serie:

  node abre.js "https://labs.google/fx/pt/tools/flow/project/7543972f-546b-4127-879e-83882fdd48dd"
  node flow-capa.js "<cole o prompt>" "<pasta do extra>/img/flow" "16:9" "flow-<nome>"
